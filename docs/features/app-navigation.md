# App Navigation

## Purpose

Give students direct access to active loans, returned loans, and the app's additional area from one consistent navigation structure.

## User Story

As a user, I want to switch between the overview, archive, and more area so that I can reach the app's main sections quickly.

## Acceptance Criteria

- The app presents Overview, Archive, and More as persistent tabs.
- Selecting a tab displays its corresponding screen.
- The selected tab uses the app's accent color.
