# App Information

## Purpose

Make the website, privacy policy, and installed app version easy to find.

## User Story

As a user, I want to open app information from the archive so that I can read
the privacy policy and check which version is installed.

## Acceptance Criteria

- An information button appears beside the BorrowBack wordmark at the top of
  the archive, matching the overview's add button.
- Tapping the button opens an information sheet.
- The sheet links to the BorrowBack website and privacy policy.
- The sheet shows the installed app version.
- The sheet has an X button to dismiss it without changing loan data.
