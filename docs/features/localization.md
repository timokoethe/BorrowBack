# English and German Localization

## Purpose

Make BorrowBack understandable to English- and German-speaking users while keeping English as the primary language.

## User Story

As a user, I want the interface and dates to follow my language settings so that I can use the app in English or German.

## Acceptance Criteria

- English is the app's primary language.
- German translations are available for user-facing loan-management text.
- The interface follows the user's selected app or system language.
- Displayed dates use formatting appropriate for the active locale.
- Dynamic sort labels and loan statuses update with the active locale.
